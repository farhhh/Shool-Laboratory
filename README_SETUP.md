# Меню научных симуляций

## Куда положить файлы

Скопируй **все файлы из архива** в корень проекта — на один уровень с папкой `Simulations` и `README.md`. Не копируй только `index.html`: для автоматической сборки нужны скрипт, настройки Netlify и файлы каталога.

- `index.html`
- `catalog.json`
- `build-catalog.mjs`
- `package.json`
- `netlify.toml`
- `robots.txt`
- `advertising.html`, `support.html`, `feedback.html`

Папку `Simulations` с уже готовыми лабораториями оставь как есть.

## Как меню находит симуляции

Сканер `build-catalog.mjs` проходит по папкам первого уровня внутри `Simulations` и берёт каждый `.html` файл, лежащий непосредственно в папке предмета (не во вложенных подпапках). Для `solar_system.html` он ищет рядом:

- `solar_system.png` — превью карточки (необязательно; если нет, будет тематическая заглушка)
- `solar_system.txt` — название и описание (необязательно)

То есть структура выглядит так:

```text
Simulations/
├── Astonomia/
│   ├── solar_system.html
│   ├── solar_system.png
│   └── solar_system.txt
├── Himia/
│   ├── atomnaya_laboratoriya.html
│   ├── atomnaya_laboratoriya.png
│   └── atomnaya_laboratoriya.txt
├── Physics/
│   ├── opticheskaya_laboratoriya.html
│   ├── opticheskaya_laboratoriya.png
│   └── opticheskaya_laboratoriya.txt
├── Informatics/
├── Biology/
└── Geography/
```

Для новых предметов подойдут папки `Informatics` (Информатика), `Biology` (Биология) и `Geography` (География). Можно использовать и русские названия папок: `Информатика`, `Биология`, `География`. Каталог создаст категорию автоматически, когда внутри папки появится хотя бы один HTML-файл симуляции.

### Формат TXT — самый простой

Первая непустая строка — название. Всё ниже — описание; можно делать несколько строк и абзацев.

```text
Солнечная система
Исследуй планеты и наблюдай, как меняется их движение. Меняй параметры и проводи собственные эксперименты.
```

Можно также использовать расширенный формат:

```text
Название: Солнечная система
Описание: Исследуй планеты и проводи собственные эксперименты.
Теги: космос, планеты, орбиты
Уровень: 7–9 класс
Время: 10–15 минут
```

Категория определяется именно папкой, в которой лежит HTML-файл, а не содержимым TXT.

## Как обновлять каталог

**Самый автоматический вариант — подключить репозиторий GitHub к Netlify.** При каждой сборке Netlify выполнит команду `npm run build` из `netlify.toml`. Сканер пересоздаст `catalog.json` по содержимому папки `Simulations`. При добавлении новой категории или HTML-файла `index.html` менять не нужно.

**При ручной загрузке ZIP через Netlify Drop** команды сборки не запускаются. Перед созданием архива один раз запусти в корне проекта:

```bash
npm run build
```

После этого добавь обновлённый `catalog.json` в ZIP и загрузи архив. При таком способе нужно повторять сборку каталога перед каждой новой ручной публикацией.

На компьютере должен быть установлен Node.js. В наборе нет сторонних npm-зависимостей.

## Временное скрытие до запуска

Сейчас в `netlify.toml` и `robots.txt` включён запрет индексации поисковиками (`noindex` и `Disallow`). Это помогает не попадать в поисковую выдачу, но **не закрывает сайт от людей, у которых есть ссылка**. Для реального ограничения доступа используй приватность проекта/защиту доступа Netlify, если она доступна в настройках твоего плана. Перед публичным запуском удали временные правила `X-Robots-Tag` из `netlify.toml` и замени `robots.txt` на разрешающий вариант.
